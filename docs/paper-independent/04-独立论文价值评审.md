## 净判断

**Go，但时间盒受控，且降级路径先写好。**

这篇论文的价值不在发现重大缺陷——现稿自己也明确不主张 Linux 缺陷——而在把一类容易被归零误读的观察（零错误与零机会的区分）变成可检验的机制命题，并给 R0 组合的底座合同提供一条可引用的设计约束。它的上限是 Computer Networks / CCR 档的扎实机制短文；中间值是并入 P1 substrate qualification 的一节；kill 条件是独立会话复现失败或系统查新撞车。

本轮检索把判断从“有条件值得做”上调为“值得做”，关键新证据见下节。

## 关键新证据：机制出处的定位

retained-program 语义并非受控切片制造的伪象，而是上游一次有据可查的性能优化引入的。commit `cb261b594b41`（bpf: Run devmap xdp_prog on flush instead of bulk enqueue，Hangbin Liu 与 Jesper Dangaard Brouer，2021-05 合入 bpf-next，随 v5.14 发布）：

- 为 I-cache 局部性与多播简化，把 devmap egress program 的执行从逐帧 enqueue 挪到 `bq_xmit_all` 批量执行；
- commit 说明明确记录了副作用：`bq->xdp_prog` 的 RCU 引用从单次程序调用延长到 bq flush；
- `bq_enqueue` 仅在 bq 首帧设置 `xdp_prog`，flush 时清空——与现稿 §3.2 的 cache epoch 定义逐字对应，交叉验证了现稿的源码解读；
- 现稿所用的 v6.8 沿用该语义，上游至今未改。

对价值评审的含义有两条。其一，问题真实性上调：现稿测到的是一个真实存在、有明确出处、上游有意为之的设计决策在跨代更新下的一致性代价，而非仪器假象；v3 单帧 epoch 与 v4 多帧 epoch 的差异也因此更可解释——epoch 长度取决于驱动与 NAPI 时序。其二，现稿有一处可立即补强：related work 与 §2.3 只引了 v6.8 源码文件，未引引入该语义的 commit；补引之后，motivation 可从“我们观察到某现象”升级为“上游 2021 年设计决策的显式一致性代价”，直接回应 so what 质疑。这条补强零成本，建议无条件采纳。

## 新颖性初查

按 R0 WS2 的字段要求记录口径：检索日期 2026-11-23，单一搜索源，每条查询命中 5 个结果；未查 DBLP、ACM DL、IEEE Xplore，故仅为初步扫描。

| 查询方向 | 命中概况 | 判读 |
|---|---|---|
| devmap `bq_xmit_all` 与 `xdp_prog` 保留语义 | 全部为 2021 年 commit 本体、内核树镜像与 netdev 邮件列表 | 无任何一致性讨论；commit 只谈 I-cache 与 RCU 生命周期 |
| eBPF/XDP 热更新一致性 | Cloudflare xdpd 的 `bpf_link` 原子切换与 tag 校验、Gcore 的 atomic replacement 与 libxdp dispatcher 实践文 | 工程讨论止步于程序级替换，未触及跨 hook retained program 与逐帧 generation 混淆 |
| consistent updates 2024–2025 | eBPF 生态综述、verifier 与安全方向研究 | 未见 devmap 出口一致性同题工作 |

判读：缝隙真实。理论近邻是 Reitblatt 的抽象层更新一致性，实践近邻是程序级原子替换与 dispatcher 模式，S1 位于两者之间未被覆盖的实现层，且 hazard 正是 5.14 批处理执行语义引入后的新属性。**投稿前仍须按 WS2 完成系统查新；若撞车，按 `CLAIM_LIFECYCLE.md` 转 retired 并记录。**

## 对 R0 组合的价值

1. **P1 的 substrate qualification 直接受益**。`RESEARCH_EXECUTION_PLAN_v0.1.md` Week 7 本就要测更新生效延迟、切换期间错误转发与策略空窗；cache-epoch condition 给出一条此前未被列入的失效模式与判据。P1 可引用该 condition（引用结论，不搬 365 vs 0 conflicts 数据，遵循 `01` 文档的 reused section limits）。
2. **P2 的配置推送一致性有真实对应物**。`jz_sniff_rn/README.md:238` 起的 steer false-ready 事件与 fail-closed 语义，与 S1 的机制命题同构，属同一问题域的两个实例；P2 的 motivation 可引 S1 的 condition 作为同域佐证。
3. **方法学迁移**。P2 证据链的痛点是四维 feeds 在最小实验室配置下全零（`evidence-map.md`）。全零究竟是没机会还是没问题，正是 S1 的暴露感知判读所回答的问题；这套方法可直接写进 P2 的实验合同。
4. **作品集与方法训练价值**。一篇把负结果、预注册缺失与暴露不等都如实结构化的论文，对学位答辩的学术可信度是正向资产，前提是 AI 声明补全且 artifact 公开。

## 主要风险

| 风险 | 影响 | 处置 |

| 复现脆弱性：v3 全为单帧 epoch，v4 依赖 threaded-NAPI 干预才出现多帧 epoch | 若独立 boot、trace-off 下现象不可见，自然暴露叙事降级为仪器可见 | go/no-go 最小复现先行，见下节 |

## 成本与时间盒

必做项全部是重跑与包装：多 boot 独立会话、等暴露匹配、observer qualification、packet-level 统计、artifact 公开、RW 系统补检、AI 声明补全、commit 引文补入。

建议把 go/no-go 收窄为一个最小复现：2 至 3 个独立 boot，仅 direct 与 clean mux 两 arm，trace-off 与 trace-on 对照。direct arm 在等暴露、非干预条件下仍出现 receiver-corroborated conflicts，即过闸，继续补全其余闸门；不出现则触发降级。

降级路径：复现失败 → cache-epoch condition 并入 P1 的 substrate qualification 一节，论文降为 CCR 短文或归档；查新撞车 → retired 并记录理由。

## 附录：Council 裁决与投稿合同决策

> 背景：2026-11-23 主理人提出判断——“S1 定位为底座资格验证知识后，此前列出的主要风险在安全的前提下似乎都不严肃了”。按多视角对抗流程以五位独立顾问审查，主理人仲裁后形成裁决，随后做出投稿合同决策。

| 顾问 | 核心判断 |
|---|---|
| 反对者 | “在安全的前提下”二义性致命：若指部署不会踩中混代窗口，那就是复现风险①的循环论证；若指 rSwitch 设计会规避，则 S1 价值坍缩为“记录了已规避的机制”，影响质疑反而加重。前置正确性知识是约束级，资格验证是门禁级，现有证据只买得起前者 |
| 本质思考者 | 定位改变内部价值记账，不改变风险性质；六条风险全是外部评审或资源型风险。真正悬而未决的是签哪份合同——独立投稿、并入 P1 资格验证章节、降级为设计约束；测度问题是“P1 的切换一致性论证是否逻辑依赖 S1” |
| 机会挖掘者 | 判断对一半：短板从研究级开放难题变成工程级施工单；且 S1 是 P2 四维指标全零困境的直接解药——全零是没机会还是没问题，正是 S1 的暴露感知判读回答的问题，条件是判读方法必须形式化 |
| 局中人（局外人） | 期刊评审看不到内部研究组合，“底座资格验证知识”翻译过去就是“作者自己项目的工程笔记”；最危险的混淆是把答辩逻辑搬进期刊，两套规则互不替代 |
| 执行者 | 少做统计、多做一次 boot：存在性证明不需要统计，但可复现性恰恰是资格验证知识的产品本身，go/no-go 从加分项升级为唯一不可降级的闸门 |

删除的弱观点：组合叙事弧线设想（不改变下一步动作，且被合同三分法覆盖）；“安全前提已被实验设计满足”（单 boot 证明不了该前提）；“罕见证据结构”自评（与正文重复）。

**裁决**：判断对一半。成立的部分——“不主张缺陷、不估计发生率”从弱点变为设计选择，短板清单有界化。不成立的部分——查新、时间挤压、AI 声明、artifact 四项与定位无关；复现脆弱性被升权而非消解；以内部定位应对外部审稿会让影响质疑加重；“安全前提”在读法澄清前不能作为论证依据。

**决策记录**：主理人于 2026-11-23 选定 **合同 (a)：独立投稿**。该选择的含义与随附纪律：

1. 六项风险原封在册，由作者承担；其中影响质疑须以去内部化措辞回应——把发现写成对任何批量出口队列使用者的通用 devmap 热更新问题，而非私人底座的验证笔记；
2. 必须正面回答“非干预时会不会发生”，回避等于把拒稿理由留给评审；
3. go/no-go 复现为不可降级闸门，协议见 `replication/README.md`，判据与三态判读已冻结；
4. artifact 公开与 AI 声明补全为投稿前置义务，修复成本以小时计；
5. 时间盒保留——挤占 P2 的机会成本不因合同选择而消失。
